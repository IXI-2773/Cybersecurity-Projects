# Imported open-source tools

![Open-source integration](assets/badges/open-source-integration.svg)

**Work type:** upstream-authored tool source. The first two integrations and one community Linux CIS import have separate, explicitly scoped synthetic examples; all copied tool source remains third-party-authored. [Portfolio projects](README.md#portfolio-projects) have a separate index.

These tools are copied release snapshots credited to their original authors. Their source is unmodified; each retains its own license. The collection's contribution varies: the earlier ssh-audit/detect-secrets snapshots have retained examples and results; community copies have pinned provenance and source-integrity checks; only the Linux CIS copy has a recorded synthetic test-root execution.

[imports.json](third_party/imports.json) records the earlier two evidence-bound integration snapshots by path and SHA-256; [community/imports.json](third_party/community/imports.json) records the AngelaMos source imports by Git blob hash; [external/imports.json](third_party/external/imports.json) pins the independent GitHub source copies. Runtime source, package metadata and notices are included; upstream test suites, build automation and test keys are excluded. Upstream READMEs are retained unchanged as source documents; use the collection examples above for commands that match this layout.

The first-party catalog checker skips upstream documentation and source. The [prior import checker](scripts/check_upstream_imports.py) checks the earlier copies and retained examples; [independent source checker](scripts/check_external_imports.py) verifies only the new upstream files and Python syntax. Current CI checks this evidence without launching SSH services or verifying credentials against network services.

Updates are manual: choose an upstream revision, review its changes, preserve its notices, refresh the import hashes and repeat only the affected example. These release snapshots do not receive automatic upstream fixes. The original tool authors are not represented as endorsing this collection.
