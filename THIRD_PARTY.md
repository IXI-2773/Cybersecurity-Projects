# Imported open-source tools

![Open-source integration](assets/badges/open-source-integration.svg)

**Work type:** upstream-authored tool source. The first two integrations have collection-developed examples; community imports are source-only. [Portfolio projects](README.md#portfolio-projects) have a separate index.

These tools are copied release snapshots credited to their original authors. Their source is unmodified; each retains its own license. The collection's contribution varies: the earlier ssh-audit/detect-secrets snapshots have retained examples and results; community copies have pinned provenance and source-integrity checks, but no collection execution claims.

[imports.json](third_party/imports.json) records the earlier two evidence-bound integration snapshots by path and SHA-256; [community/imports.json](third_party/community/imports.json) separately records the new source-only imports by Git blob hash. Runtime source, package metadata and notices are included; upstream test suites, build automation and test keys are excluded. Upstream READMEs are retained unchanged as source documents; use the collection examples above for commands that match this layout.

The first-party catalog checker skips upstream documentation and source. A separate [import checker](scripts/check_upstream_imports.py) checks their exact bytes and Python syntax, along with the retained examples. Current CI checks this evidence without launching SSH services or verifying credentials against network services.

Updates are manual: choose an upstream revision, review its changes, preserve its notices, refresh the import hashes and repeat only the affected example. These release snapshots do not receive automatic upstream fixes. The original tool authors are not represented as endorsing this collection.
