# Security and project scope

The public labs use fabricated, generated, recorded-emulation or explicitly isolated inputs as described in each project. Review each README before running its tools.

Do not post credentials, personal logs, proprietary code or private repository material in issues or pull requests. Use the maintainer's GitHub contact channels for sensitive reports.

Celestial Resonance and Research AI Infrastructure are separate private projects. Their public summaries do not authorize access to their source or systems.
